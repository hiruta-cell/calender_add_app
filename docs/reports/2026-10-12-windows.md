## 別件で分かったこと

### 1. メモ帳からコピーした文章の「〜」が「?」になった（B-10 の確認中）
- `demo/texts/1-mail-ja.txt` の「14:00〜15:30」の「〜」は U+301C（ファイルは BOM なしの UTF-8）。
- メモ帳でファイルを開いて全文をコピーし、Ctrl+Shift+U（B-10）で読み取ると、左の欄が「14:00?15:30」になり、候補の元の表記は「10月22日(木) 14:00」だけだった。Ctrl+V で貼り付けたとき（B-12）も同じく「?15:30」だった。
- 同じファイルの内容を PowerShell の `Set-Clipboard` でクリップボードに入れて Ctrl+Shift+U を押すと、「14:00〜15:30」と正しく入り、元の表記は「10月22日(木) 14:00〜15:30」になった。
- 分かっているのは、「メモ帳からのコピーだとき『?』になる」「PowerShell から入れたときは『〜』のまま」ということだけ。**原因は不明**（メモ帳のコピーの時点で『?』になっているのか、別の要因かは、クリップボードの中身を直接見ていないため確かめていない）。
- 開始時刻だけを使う仕様のため、終了時刻の表示には影響しないが、「〜」が「?」になる点は Windows の利用者に見える。

### 2. 手順書 D-2 が、アプリの仕様と合っていない
- `docs/WINDOWS-CHECK.md` の D-2 は「範囲を選んで読み取るキーを Ctrl+Shift ＋ U にする」だが、設定画面に「U は範囲キャプチャには選べません」と表示され、キーの一覧に U は並んでいない（仕様どおりの動作）。
- 代わりに J を選んで確認し、合格（表示が「画面から読み取る（Ctrl+Shift+J）」に変わり、Ctrl+Shift+J で範囲選択が始まり、Esc で中止できた）。

### 3. ログイン時の自動起動（E-2）が、起動時にエラーになった（不合格）
- E-1 で自動起動をオンにして保存し、Windows からサインアウトしてサインインし直すと、「Error launching app」のダイアログが出た。表示（パスは置き換え）：
  ```
  Unable to find Electron app at C:\WINDOWS\system32\"（ユーザーのフォルダ）\GitHub\calender_add_app"
  Cannot find module 'C:\WINDOWS\system32\"（ユーザーのフォルダ）\GitHub\calender_add_app"'
  ```
  アプリは起動しなかった（トレイのアイコンの確認は、このエラーのため行っていない）。
- レジストリ（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）の値 `electron.app.Electron` の実際の中身（パスは置き換え）：
  ```
  "（ユーザーのフォルダ）\GitHub\calender_add_app\node_modules\electron\dist\electron.exe" "\"（ユーザーのフォルダ）\GitHub\calender_add_app\"" --hidden
  ```
  フォルダのパスが `"\"…\""` のように、二重に引用符で囲まれている（引用符の文字が引数の中身に残る形）。
- コードでの対応する箇所：`electron/desktopIntegration.js` の `buildWindowsLoginItemSettings`（`args: [quoteWindowsArgument(appPath), HIDDEN_START_ARGUMENT]`）が、パスを `"…"` で囲んだ文字列を `args` に渡している。`quoteWindowsArgument` は `"${value}"` を返す。
- 分かっていること：レジストリの値に二重の引用符があること。エラーの表示が、引用符の文字を含んだ文字列をアプリのパスとして `C:\WINDOWS\system32\` の下で探していること。
- 推定（未確認）：`app.setLoginItemSettings` の `args` を Electron 自身が引用符で囲んで登録するため、コード側で囲むと二重になる。確かめるには、`args` に引用符なしのパスを渡して登録し直し、レジストリの値が `"…\electron.exe" "（フォルダ）" --hidden` になるかを見る必要がある。
- 影響：フォルダのパスに空白がない場合も同じ形（`"\"C:\…\"" `）になるはずで、空白のある PC に限らないと考えられる（未確認）。このエラーのまま、サインインのたびにダイアログが出る。
- 現在の PC の状態：このレジストリの値が残っている。E-4 で設定から自動起動をオフにして保存すると消える想定（確認する）。

## 直す案（提案）
- `docs/WINDOWS-CHECK.md`（D-2）：「Ctrl+Shift ＋ U」を、選べるキー（例：J）に変える。期待する結果の「画面から読み取る（Ctrl+Shift+U）」も合わせて変える。
- `electron/desktopIntegration.js`（`buildWindowsLoginItemSettings`）：`args` に渡すパスを、引用符で囲まない文字列にする（`quoteWindowsArgument` の検査だけを使い、囲む処理は Electron に任せる）。変えたあと、登録後のレジストリの値で `"…electron.exe" "（フォルダ）" --hidden` の形になることを確かめる。`getLoginItemSettings` に渡す `args` も同じにする（登録時と揃える）。単体テストで、`args` に引用符が含まれないことを確かめる。自動確認（`test:smoke`）は本物の登録を作らないため、この不具合を見逃した可能性がある。
- 「?」の件：Mac 側で、`clipboardImport` が文字を変えていないこと（Windows のクリップボードの形式の違い）を確かめる余地がある。Windows 側から送った情報では原因を特定できていない。
