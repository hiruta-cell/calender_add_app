# Windows での確認の手順（最終版の確認）

依頼者が Windows で行う確認です。ここまで確かめられたら、この版を最終版とします。
所要時間：30〜40分（ログアウト・ログインを1回含みます。初回は Electron 本体のダウンロードに数分かかります）

確認の番号（例：A-3）ごとに OK／NG を記録し、最後の「8. 結果の伝え方」で教えてください。
使う文面・画像はすべて架空のもの（リポジトリの `demo/` フォルダ）です。

## 1. 準備

**コマンドプロンプト**を開きます（スタートメニューで「cmd」と入力）。
PowerShell ではなくコマンドプロンプトを使ってください（PowerShell では設定により `npm` が動かないことがあるため）。

```
node -v
git --version
```

- `node -v` が **v22.12.0 以上**であること（v24 なども可）
- **アプリが常駐していれば、先に終了してください**（タスクトレイのアイコンを右クリック →「終了」）。古い版が動いたままだと、多重起動の防止のため新しい版を `npm start` しても起動せず、古い版で確認することになります
- 前回の確認で作った `%USERPROFILE%\calender_add_app` フォルダがある場合は、アプリを終了してから、フォルダの名前を `calender_add_app_old` などに変えておいてください（新しいフォルダで clone からの起動を確かめるため。前回作ったデスクトップのアイコン・自動起動があれば、先に「7. 後片付け」をしてください）

## 2. ダウンロードと起動（ゴール G5）

```
cd %USERPROFILE%
git clone https://github.com/hiruta-cell/calender_add_app.git
cd calender_add_app
npm ci
npm start
```

## 7. 後片付け（確認が終わったら）

1. 自動起動がオンなら、設定でオフにして保存する
2. トレイのメニューの「終了」でアプリを終了する
3. 不要なら、デスクトップのアイコンと、`calender_add_app` フォルダ（名前を変えた古いフォルダも）を削除する

## （任意）自動の確認も実行する

アプリを終了してから、コマンドプロンプトで実行します（2つ目は、ウインドウが一瞬開いて自動で閉じます。約30秒）。

## うまくいかないとき

| 表示・症状 | 対処 |
|---|---|
| `'node' は、内部コマンドまたは外部コマンド…として認識されていません` | Node.js が入っていません。https://nodejs.org から LTS 版を入れて、コマンドプロンプトを開き直してください |
| `EBADENGINE` / `Unsupported engine` | Node.js が古いです（22.12 以上が必要）。更新してください |
| `このシステムではスクリプトの実行が無効になっているため…` | PowerShell で実行しています。コマンドプロンプトで実行してください |
| `Electron failed to install correctly` | ダウンロードに失敗しています。`rmdir /s /q node_modules\electron` のあと `npm ci` からやり直してください。会社のネットワークで GitHub からのダウンロードが止められている可能性もあります |
| 「起動できません」と表示される | 一度 `npm start` で起動してください（画面のファイルが作られます） |
| `npm start` で何も起きない | アプリがすでに起動しています（多重起動の防止）。タスクトレイのアイコンを確かめてください |
| 「ホットキーを登録できませんでした」と出る | ほかのアプリが Ctrl+Shift+Y か Ctrl+Shift+U を使っています。設定で別のキー（Ctrl+Shift の部分を変えると両方変わります）を選んでください。ボタンやトレイのメニューはそのまま使えます |
| デスクトップのアイコンを作れない | 同じ名前の別のファイルがデスクトップにあります。名前を変えてから押し直してください |
| 縦書きのデモ画像（`3-notice-vertical.png`）が文字化けする（Mac では読める） | 調査中（10/12。PC を直接操作したときに起き、Mac からリモートデスクトップで操作したときは読めた。画面の状態・GPU の違いを疑っている）。起きたら、アプリを終了する前に `npm run ocr:diagnose:canvas` を実行して表示を送ってください。アプリを終了し、`npm start` で起動し直してください。それでも読めなければ、`git pull` のあとアプリを終了し、コマンドプロンプトで `npm run ocr:diagnose`・`npm run ocr:diagnose -- --electron`・`npm run ocr:diagnose:canvas` を実行して、表示をすべて貼り付けて送ってください（それぞれ1分ほど。デモの架空の画像だけを読みます） |
