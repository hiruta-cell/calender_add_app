# Windows での起動確認の手順

所要時間：10〜15分（初回は Electron 本体のダウンロードに数分かかります）

## 1. 準備の確認

**コマンドプロンプト**を開きます（スタートメニューで「cmd」と入力）。
PowerShell ではなくコマンドプロンプトを使ってください。PowerShell では設定により `npm` が動かないことがあるためです。

次の2つを実行して、バージョンが表示されることを確かめます。

```
node -v
git --version
```

- `node -v` が **v22.12.0 以上**であること（v24 なども可）
- `git` が見つからない場合は、手順2の「Git がない場合」を使います

## 2. ダウンロード

ホームフォルダに移動して、リポジトリを取得します。

```
cd %USERPROFILE%
git clone https://github.com/hiruta-cell/calender_add_app.git
cd calender_add_app
```

**Git がない場合**：ブラウザで https://github.com/hiruta-cell/calender_add_app を開き、「Code」→「Download ZIP」でダウンロードして展開します。
コマンドプロンプトで、展開したフォルダ（`calender_add_app-main`）に `cd` で移動してください。

## 3. インストールと起動

```
npm ci
npm start
```

- `npm ci` は、記録されたバージョンどおりに部品を入れます。最後に `found 0 vulnerabilities` と出れば正常です。
- 初回の `npm start` では `Downloading Electron binary...` と表示され、数分かかることがあります。

## 4. 確認すること

ウインドウが開いたら、次を確かめてください。

| # | 確認すること | 期待する結果 |
|---|---|---|
| 1 | 「カレンダー登録ツール」のウインドウが開く | 左に入力欄、右に「日時の候補」 |
| 2 | 下の架空の文章をコピーして、左の欄に **Ctrl+V** で貼り付ける | 貼り付けられる |
| 3 | 「日時を抽出」を押す | 右に候補が3件表示され、左の文章の日時部分が黄色になる |
| 4 | 「予定の内容」を見る | 件名・場所・オンライン会議URL が入っている |
| 5 | 1件目（10月15日 14:00〜15:00）にチェックを付け、「選んだ 1 件をGoogleカレンダーで開く」を押す | 既定のブラウザで Googleカレンダーの予定作成画面が開き、日時と件名が入っている（**保存は不要**です。タブを閉じてください） |
| 6 | ウインドウ右上の × で閉じる | アプリが終了し、コマンドプロンプトに入力できる状態に戻る |

貼り付ける架空の文章：

```
件名：【架空】第3回 定例会のご案内
日時：10月15日(木)14時〜15時
場所：オンライン（Zoom）
参加URL：https://zoom.us/j/0000000000?pwd=example
予備日：来週火曜 午後3時半から
資料の締切は明日です。
```

「来週火曜」「明日」の日付は、確認する日によって変わります。

## 5. （任意）自動の確認も実行する

時間があれば、次も実行してください。Windows でのテストと、画面の自動操作による確認を行います。
2つ目の確認では、ウインドウが一瞬開いて自動で閉じます。アプリを閉じてから実行してください。

```
npm test
npm run test:smoke
```

最後の行の結果を教えてください。
- `npm test` → `ℹ pass ◯◯` と `ℹ fail ◯` の行
- `npm run test:smoke` → `合格 ◯◯ 件 / 不合格 ◯ 件` の行

## 6. うまくいかないとき

| 表示 | 対処 |
|---|---|
| `'node' は、内部コマンドまたは外部コマンド…として認識されていません` | Node.js が入っていません。https://nodejs.org から LTS 版を入れて、コマンドプロンプトを開き直してください |
| `EBADENGINE` / `Unsupported engine` | Node.js が古いです（22.12 以上が必要）。更新してください |
| `このシステムではスクリプトの実行が無効になっているため…` | PowerShell で実行しています。コマンドプロンプトで実行してください |
| `Electron failed to install correctly` | ダウンロードに失敗しています。`rmdir /s /q node_modules\electron` のあと `npm ci` からやり直してください。会社のネットワークで GitHub からのダウンロードが止められている可能性もあります |
| 「起動できません」と表示される | `npm start` で起動してください（`electron .` を直接実行すると画面のファイルが作られません） |

## 7. 結果の伝え方

次を教えてください。画面の画像を送る場合は、個人情報が写っていないことを確かめてください。

- Windows のバージョン（例：Windows 11）と `node -v` の結果
- 手順4の 1〜6 の結果（OK／NG）
- NG の場合は、表示されたメッセージ
- 手順5を実行した場合は、その結果の行
