カレンダー登録ツール

メールやメッセージの文章から日付・時刻を見つけ出し、Googleカレンダーの予定作成画面を開くデスクトップツールです。

できること

  • 文章を貼り付けて、日時の候補を一覧で確かめられます。
  • 件名・場所・メモを自動で入れ、Googleカレンダーの予定作成画面を開きます。
  • コピーした文章は、ショートカットキーひとつで読み取れます。
  • 画面の範囲や画像からの読み取りは実験機能です（読み間違いがあるため、必ず内容を確かめてください）。

プライバシー

日時の解析はすべて、お使いの PC の中で行います。文章や画像を外部のサービスへ送ることはありません。

外部へ送られるのは、「保存」を押して登録した予定の内容だけです（Googleカレンダーの画面で行います）。

はじめかた

動作には Node.js 22.12 以上 と Git が必要です。Windows と Mac で使えます。

ターミナル（Windows は「コマンド プロンプト」か「PowerShell」）で、次の順に実行します。

git clone https://github.com/hiruta-cell/calender_add_app.git
cd calender_add_app
npm ci
npm start

「カレンダー登録ツール」のウインドウが開けば成功です。手順の詳細と試し方は README にあります。

README（まず試す）を開く

注意

  • インストーラーはありません。上の手順でプロジェクトのフォルダから起動します。
  • ウインドウを閉じてもアプリは終了せず、タスクトレイ（Mac はメニューバー）に残ります。
  • Mac で画面の範囲を読み取るには、初回に画面収録の許可が必要です。
